## 4. 六维视觉提示词

1. **主体**：人物、产品、动作、数量、识别特征。
2. **环境**：地点、时间、空间层次、背景材质与真实上下文。
3. **气质**：颜色、纸张/界面材质、形状语言、强调色和细节密度。
4. **光线**：方向、软硬、色温、反差与阴影；真实照片不伪造现场光线。
5. **镜头**：景别、视角、焦段感、人物位置和证据区留白。
6. **排版**：精确文案、层级、换行、对齐、高亮位置和手机缩略图可读性。
