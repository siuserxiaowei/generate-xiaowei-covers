# Security and privacy policy

## Reporting

Use GitHub's private security-advisory flow for vulnerabilities, accidental credential exposure, private signed URLs, or sensitive personal data. Do not open a public issue containing secrets or private media.

## Supported version

Security and privacy fixes are applied to the default branch.

## Repository safety rules

- Never commit API keys, access tokens, cookies, private GitHub URLs, or expiring signed download URLs.
- Strip EXIF/GPS metadata from photos before committing them.
- Treat customer screenshots, internal dashboards, email, and terminal output as sensitive until reviewed.
- Do not present a reconstructed UI as an official screenshot.
- Keep source URLs and licensing notes, but redact query parameters that contain credentials or signatures.
