# Changelog

All notable changes to this project are documented here.

## 0.2.0 — 2026-08-16

- Added an explicit `COVER_PROMPT.md` artifact to every generated project.
- Repositioned the public documentation around cover prompts, content routing, evidence, and multi-surface output.
- Replaced compressed contact sheets with clickable full-resolution PNG examples.
- Reimplemented the WeChat template as an independent six-route layout system.
- Added a public high-resolution gallery and clearer portrait, trademark, and source boundaries.

## 0.1.0 — 2026-08-16

- Added six evidence-driven content routes.
- Added 1080×1440 Xiaohongshu templates.
- Added independent 2100×900 and 1080×1080 WeChat cover pairs.
- Added paired-review previews.
- Added lower-left contextual portrait strategy for 3:4 and 21:9.
- Added project scaffolding with `FACTS.md`, `SOURCES.md`, and license copying.
- Added selective export by route, node ID, and output filename.
- Added Playwright rendering with local Chrome/CDP fallback.
- Added source, privacy, trademark, and AGPL publication gates.
