# 数量、风格与比例

`single` 做一个内容适配方向；`style_pack` 做明确数量的不同完整方向；`series` 延续用户指定的同款语言。跨次任务保持身份，不默认保持同一风格。

“整套”依据上下文解释：优化整套Skill是工作流请求，文案+各平台封面是发布包，只有明确的多张不同风格请求才扩展设计方向。不要把它固定解释成五张。

风格由字体字效、色彩、材质、空间组织与图像处理共同决定。比例改变、位置改变、人物姿势改变和换道具是同风格的变体；HTML与生图是制作方法，不算风格。

使用 `COVER_PLAN.json` 规划全部方向与主体关系；计划里的 style ID、DNA距离或描述词只帮助筛选候选。实际图片需要重新记录观察到的构图字段并并排检查视觉语言。脚本能查记录和尺寸，不能自动看懂像素。

历史 `STYLE_SELECTION.json` / `STYLE_SET.json` 用于回放预设，保留兼容。旧“不同DNA字符串至少3项”的数字仅为候选筛选，不作为成图通过理由。新请求优先 `build-cover-plan.mjs`。具体方法见 [art-direction.md](art-direction.md)、[cover-plan.md](cover-plan.md)。
