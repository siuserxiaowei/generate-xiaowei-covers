# 预设与引擎

`assets/style-presets.json` 是候选目录。新任务先完成内容/场景策划，再选完整方向；不自动套历史series或五张pack。

- `original` / `editorial` 适合独立HTML与真实照片；保留可编辑画布。
- 其余方向默认内置生图，提供已查看的身份主图及本次主题对象。
- `workbench`、`blueprint`、`handbook`、`type-led` 为本地独立编写的方向，分别强调实物场景、工程索引、学习路径、文字主视觉。
- `atutun` 参考用户指定的原仓库，不是v2。它的八种模板是同一风格的内容/版式变化，不能计为八个审美方向。

完整策划优先使用 `scripts/build-cover-plan.mjs`。旧选择器保留记录回放与显式候选探索；不调用生图，不证明图片风格差异。`targetPixels` 是目标参考尺寸，实际原图尺寸必须读取验证。seed只复现选择，不保证像素一致。

Preset 的 portrait/layout 表述给出历史示例；本次plan根据视觉焦点明确的主体位置、动作和镜头优先。不把字体、材质、色彩从几个方向随手拼成未定义的风格，也不把生成引擎当审美。

每次生成记录全提示、参考角色、工具、实际路径/宽高和修正原因。成品保存项目covers/；预览与原稿同项目，返回图片。是否发布由用户另行决定。没有生图工具时只能交付策划/HTML适用结果，不能把提示词称为已生成封面。
