# 把参考转成当前主题的设计

读取用户指定参考，分别记录：字体字效、色彩材质、空间/层级、对象处理与人物互动。提炼方法后换成当前原文的标题、本人身份与真实对象，不复制完整原图或其他作者的脸。

先写“读者为什么点开”和“人物与主题对象做什么”，再选完整艺术方向。参考提供美学方法，内容决定主视觉和布局。具体方法见 [art-direction.md](art-direction.md)，三个指定仓库的核验与使用边界见 [upstream-research.md](upstream-research.md)。

风格库数量不能当成功率：固定右侧人像/举食指即使配色不同仍可能换皮。候选DNA字段、不同引擎和源仓库名字也不是实际视觉证明。输出需要看完整画面、240px缩略图及并排结果；记录真正看到的主视觉、站位、动作、场景与空间语法。

明确同款时保持其视觉语言，否则按新主题选择方向。照片默认锁身份，动作和场景服务内容；原照纪实才保留原像素/姿势。不能为模仿参考伪造界面、数字、合影或本人体验。
