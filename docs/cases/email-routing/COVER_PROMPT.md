# COVER PROMPT / 封面执行提示词

## 0. 原始需求

- 用户原话：把飞书草稿完整润色、排版并生成相对应封面，展示整套流程效果
- 原始链接：<[private draft link withheld]>
- 发布平台：`wechat_official_account`
- 目标画幅：`2100×900`、`1080×1080`
- 受众：想管理多个邮箱身份，或需要批量发信的个人与小团队
- 作者立场：先分清需求，再选择邮箱与发信系统

## 1. 内容判断

- 主路由：`workflow`
- 选择理由：文章的首要价值是一条决策路径，不是单一产品评测或官方公告解读
- 读者点击后首先得到什么：判断自己需要更多地址、独立账号，还是专业发信系统
- 一句话核心结论：邮箱数量可以增加入口，但不能替代投递信誉
- 事实与观点边界：三条路径是编辑总结，标注为“选择路径（示意）”；不把它冒充官方流程

## 2. 各画幅精确文案

| 公众号 1:1 | 邮箱 ≠ 发信能力 | 发信能力 | EMAIL ≠ DELIVERY · 选择指南 | 不放小字 |

## 3. 证据模块

- 主证据类型：决策流程示意
- 主证据来源：发布稿中的需求分流和四层概念
- 画面要证明的内容：更多地址、独立账号、更多发送对应三类不同方案
- 需要显式标注为“示意”的元素：右侧三通道决策图
- 不进入画面的次要信息：平台限额数字、产品名单、退信案例数字

## 4. 六维视觉提示词

1. **主体**：小伟真实活动照片位于左下；右侧为三个并列决策通道。
2. **环境**：米白编辑部纸张底纹，黑色细线结构，橙色强调。
3. **气质**：理性、克制、像一张可保存的判断卡；无科技霓虹和无关邮箱图标堆砌。
4. **光线**：沿用真实照片原始光线，不重绘人物。
5. **镜头**：21:9 左侧标题与人物、右侧决策证据；人物保留脸、手、话筒与动作上下文。
6. **排版**：主标题严格使用“邮箱多，不等于发得出去”；方图独立使用“邮箱 ≠ 发信能力”，保证 360px 缩略图可读。

## 5. 分画幅构图

### 公众号 2100×900

- 标题与人物占左侧约 42%，人物位于左下，不压标题。
- 证据模块占右侧约 50%–56%。

## 7. 保留项与禁止项

### 必须保留

- 宽图人物左下，方图纯排版
- “选择路径（示意）”标签
- 三条路径：更多地址 / 独立账号 / 更多发送
- 主标题和方图标题的精确文案

### 必须避免

- 不伪造官方页面、限额、投诉率、投递率或用户引语。
- 不粗暴裁断人物的脸、手、话筒和动作相关物件。
- 不把 21:9 机械裁成 1:1。
- 不加入未进入 `FACTS.md` 的事实数字。
